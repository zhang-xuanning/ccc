# Windows 桌面产品名称变更

[English](guide.md) | 中文

## 变更

Windows 桌面产品名称由 DeepSeek Harness 改为察心智能。可执行文件、安装目录和 Electron 用户数据目录可能随产品名称改变；覆盖升级和旧设置的访问需要在 Windows 上验证。

## 迁移

1. 测试升级前备份原安装和用户数据，不要删除旧目录。
2. 分发新安装包前，在 Windows 上验证已安装的快捷方式、旧设置和更新行为。如果看不到原数据，保留两个目录，并在复制或删除任何内容之前调查原因。
