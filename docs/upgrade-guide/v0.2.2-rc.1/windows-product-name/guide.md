# Windows desktop product name changes

English | [中文](guide.zh.md)

## Change

The Windows desktop product name changes from DeepSeek Harness to 察心智能. The executable, installation directory and Electron user-data directory may change with the product name; in-place upgrades and access to existing settings require Windows verification.

## Migration

1. Back up the existing installation and user data before testing an upgrade. Do not delete the old directories.
2. Verify the installed shortcut, existing settings and update behavior on Windows before distributing the new installer. If existing data is not visible, retain both directories and investigate before copying or deleting anything.
