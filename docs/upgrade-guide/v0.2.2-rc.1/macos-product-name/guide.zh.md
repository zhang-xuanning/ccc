# macOS 桌面应用名称变更

[English](guide.md) | 中文

## 变更

macOS 应用包和可执行文件改名为察心智能。Electron 的默认用户数据目录也随应用名称变化，原产品目录中的设置不会自动迁移。

## 迁移

1. 安装更名应用前备份旧应用的用户数据，不要删除旧目录或共享的 `.dsh` 目录。
2. 确认新应用可以打开，并在移除旧应用前检查设置。如果设置缺失，保留旧数据，不要合并正在运行的应用数据目录。
